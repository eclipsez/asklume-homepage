# AskLume 高质感卡片区域改版设计

## 目标

以用户在 2026-08-12 提供的最新参考图为唯一视觉依据，重做首页“为什么选择问答光源”和“三大信息支柱”两个区域，提高玻璃材质、空间层级和交互质感，同时保持既有文案、语义结构和响应式能力。

## 明确范围

### 删除

- 从首页完整删除 `TrustStrip` 客户信赖区，包括信任说明以及华为、腾讯、阿里巴巴、字节跳动、小米、中国平安、美的集团品牌条。
- 删除相应的页面渲染、未再使用的组件引用和针对该区的测试断言。
- 不删除内容配置中的品牌数据，除非静态检查确认没有其他消费者；若无消费者则一并删除相关类型和测试，避免遗留死代码。

### 重做

- `BenefitsSection` 三张横向卡片。
- `PillarsSection` 三张信息支柱卡片。

### 不改

- Hero、平台能力、诊断 CTA、移动端概览、页脚及其文案。
- 两组卡片现有标题、说明和链接目标。
- 全站主色仍为深海军蓝、冷蓝和紫色，不引入与品牌无关的强烈颜色。

## 视觉系统

### 背景与卡片

- 页面背景维持接近白色，并加入极弱的冷蓝环境光，让卡片从背景中自然浮起。
- 卡片使用带微量蓝紫色的半透明白色表面、细冷色边框、柔和多层阴影和内高光。
- 桌面端卡片比例、圆角、间距和文本位置按最新参考图校准；不能退化为普通白底图标卡片。
- 六张卡片均使用透明蓝紫玻璃艺术装饰，装饰在卡片边缘被自然裁切，并避免遮挡文字。

### Benefits 卡片

- 移除现有方形图标块。
- 三张卡片保持标题、两行说明和“了解更多”链接。
- 玻璃装饰分别布置在左侧、右下/中右、右侧，形成与参考图一致的不对称构图。
- 文本区域根据装饰方向调整安全留白，桌面端保持明确的视觉节奏。

### Pillars 卡片

- 增加 `01`、`02`、`03` 大号渐变编号，编号是信息层级，不只是装饰。
- 标题、核心说明和其余要点按参考图重新排版；首行能力说明保持比普通要点更突出。
- 卡片之间使用细线、渐变圆点和短虚线构成流程连接，连接元素不进入辅助技术阅读顺序。
- 每张卡片同样加入边缘裁切的玻璃艺术装饰，但装饰不与 Benefits 卡片机械重复。

## 玻璃艺术素材

- 以用户提供的参考图为形态、颜色和透明感依据，重建独立透明背景的蓝紫玻璃艺术素材。
- 素材以透明 PNG 保存为设计源文件，并生成透明 WebP 供网页加载；不直接把整张截图裁进页面，不把截图文字或背景嵌入卡片。
- 每个素材都作为装饰图处理，使用空替代文本或隐藏于辅助技术。
- 控制文件尺寸，避免六张卡片重复加载多个超大文件；优先复用少量高质量素材，通过位置、裁切、旋转和缩放形成变化。

## 鼠标与键盘交互

- 支持精细桌面指针的设备上，卡片随鼠标位置产生局部冷色光泽，玻璃艺术产生极小幅度的景深位移。
- 悬停反馈限制为轻微上浮、阴影深化、边框亮度变化和局部光泽，不做大幅缩放或持续漂浮。
- “了解更多”链接保持清晰键盘焦点，箭头只做短距离位移。
- 卡片本身不是按钮，不伪装成可点击控件；鼠标效果不改变语义。
- `prefers-reduced-motion: reduce` 下取消位移和过渡，仅保留立即出现的颜色或阴影反馈。

## 响应式

- 901 像素及以上使用三列布局，卡片比例接近参考图。
- 769 至 900 像素使用居中的单列布局，最大宽度 680 像素，避免标题和正文拥挤。
- 768 像素及以下使用手机单列卡片，保留玻璃装饰、编号和层次，但关闭鼠标跟随与景深位移。
- 所有支持宽度不得产生页面横向滚动，玻璃装饰必须在卡片内部裁切。

## 实现边界

- 使用 React、TypeScript、CSS Modules 和现有 Motion 能力，不新增运行时设计库。
- 指针位置通过可复用的轻量卡片组件或 Hook 写入 CSS 自定义属性，避免每张卡片重复实现事件逻辑。
- 不使用全局鼠标监听；只在卡片自身指针事件范围内更新效果。
- 保持现有 section heading、article heading 和 `aria-labelledby` 关系。

## 测试与验收

- 测试先行：先更新测试证明客户信赖条消失、编号存在、卡片结构和无障碍关联保持正确，再实现。
- 单元测试与生产构建必须通过。
- 视觉回归至少检查 1440、1024、390 和 360 像素宽度。
- 验收重点：卡片比例、文字对齐、玻璃装饰位置、流程连接、阴影层次、鼠标光泽、移动端无溢出以及减少动态效果模式。
- 最终页面不能保留现有普通方形图标卡片的视觉痕迹。
